# .powerup — Power-Up Kit memory

This folder is Claude's memory for this project, made by [Power-Up Kit](https://github.com/junaid-creo/power-up-kit).

- `active-client` — which client Claude is working for right now
- `clients/<client>/` — profile, brand, tone of voice, SEO and decisions for each client
- `agency.md` — your own agency's details, used for proposals and reports
- `reports/` — audits and checks Claude has run

**Never put passwords, API keys, tokens or card details in this folder.** Write only *where* access is kept.

You can edit any file by hand. Commit this folder to git if you want your whole team (and their Claude) to share the same memory.
