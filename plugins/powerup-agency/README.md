# Power-Up Kit — Agency

**Skill:** `proposal` — turns call notes, a brief or an audit into a client proposal: the client's problem in their words, goals, approach, scope with an explicit "not included" list, timeline, three pricing options and next steps. Prices come only from you or your agency profile — unknown prices stay as `[PRICE]`. A checker catches leftover template text, totals that don't add up, mixed currencies and expired quotes, and a renderer makes a branded page you can print to PDF.

Requires Node.js 18+ and installs **powerup-core** automatically. Set up your details first with the `agency-profile` skill.

Docs: https://github.com/junaid-creo/power-up-kit
