# Power-Up Kit — SEO

**Skill:** `seo-audit` — crawls a website politely (respects robots.txt), runs 30 technical and on-page checks, measures mobile speed with Google PageSpeed Insights, scores the site out of 100 and writes a prioritised fix list with the affected URLs. When Google Search Console, Ahrefs or Semrush is connected, it adds real search data — and never invents traffic or ranking numbers.

Reports are saved to `.powerup/reports/` and linked in the active client's `seo.md`. Requires Node.js 18+ and installs **powerup-core** automatically.

Docs: https://github.com/junaid-creo/power-up-kit
